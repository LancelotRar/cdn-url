GitHub 加速地址

粘贴 GitHub 源地址，一行一条，得到可用的加速地址。

支持的 6 类源地址与示例
仓库单文件 · blob 页
https://github.com/MetaCubeX/meta-rules-dat/blob/meta/geo/geoip/ad.mrs
直链 · raw
https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/refs/heads/meta/geo/geoip/ad.mrs
也接受旧式 /{owner}/{repo}/raw/{ref}/{path} 与去掉 refs/heads/ 的写法。
gist 页面
https://gist.github.com/{user}/{id}
页面地址会被落成 gist 直链，只取 gist 的第一个文件。
gist 直链 · raw
https://gist.githubusercontent.com/mn9ri4jdm5/fd2e299390c88720b4cb026b2795126a/raw/53489_qctld.md
release 资产
https://github.com/{owner}/{repo}/releases/download/{tag}/{file}
归档包
https://github.com/{owner}/{repo}/archive/refs/heads/{ref}.zip

tree 目录页、api.github.com、codeload.github.com 与仓库首页不支持。

jsDelivr 的三个备用入口与 cdn.jsdelivr.net 能力相同，不单独列出。 ✓ 支持，— 不支持；窄屏可左右滑动表格查看全部列。
