# 04: 批量与卡片

## Answer

**做了什么**

- `src/normalize.ts` 新增 `identityOf`：仓库单文件用 `{owner, repo, ref, path}` 四元组，gist 用 `{user, gistId}`，两者都不含查询串（同一文件换 token 仍是等价源）；release 资产与归档包用归一化后的原始地址。
- `src/convert.ts` 按输入行顺序记录标识首次出现的卡片序号：同标识的后出现卡片 `equivalentTo` 指向第一次出现的卡片（1 起算，含被拒绝卡片占用的序号），两张都保留、各自成卡；被拒绝的卡片不参与等价判定。
- `src/main.ts` / `index.html`：卡片头部保留源地址，有加速地址的卡片才渲染「复制本组」（复制该卡全部地址，一行一条）；页面级「复制全部」按卡片顺序摊平所有地址，没有任何地址时禁用；等价标注文案由 `Card.equivalentTo` 驱动，渲染为「与第 N 条等价」。复制仍走既有 `src/clipboard.ts`。
- 未实现能力标签与矩阵（工单 05 范围），未改服务注册表数据；合并集成分支时保留了两侧功能。
