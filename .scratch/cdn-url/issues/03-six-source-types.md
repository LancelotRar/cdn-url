# 03: 六类源与六种拒绝

**What to build:** 我能粘四类源里的任意一种——仓库单文件、gist 直链、release 资产、归档包——每条只出现**真正能服务它**的服务，八个服务之间的能力差异第一次真正起作用。粘错东西时我得到的是一句具体原因，不是笼统的格式错误。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 仓库单文件产出 8 个加速地址（两个路径重排式 + 六个前缀拼接式）
- [ ] gist 直链产出 7 个，`github.chenc.dev` 不出现
- [ ] gist 页面地址 `gist.github.com/{user}/{id}` 与 gist raw 直链产出完全相同的结果
- [ ] release 资产产出 6 个前缀拼接式地址，两个路径重排式服务不出现
- [ ] 归档包产出 6 个前缀拼接式地址，两个路径重排式服务不出现
- [ ] release 资产与归档包的地址原样透传，不被重排成 `gh/` 路径
- [ ] `tree` 目录页被拒绝，理由是目录页不支持
- [ ] `api.github.com` 被拒绝，理由与 `tree` 不同
- [ ] `codeload.github.com` 被拒绝，理由与上两者不同
- [ ] 仓库首页被拒绝，理由是缺少文件路径
- [ ] 非 GitHub 域名被拒绝，理由是域名不支持
- [ ] 无法识别的路径形状被拒绝，理由是形状无法识别
- [ ] 旧式 `github.com/{owner}/{repo}/raw/{ref}/{path}` 与 `blob` 页产出相同结果
- [ ] `?raw=true` 被丢弃；其他查询串原样保留；fragment 被丢弃
- [ ] 测试覆盖四类源各至少一条、六种拒绝各一条
